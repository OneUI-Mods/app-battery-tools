# App Battery Tools

対象アプリごとの不要な電池消費を抑えるVector / Xposedモジュールです。Android 16／17、libxposed API 102に対応します。

## 対応機能

| アプリ | 個別に切り替えできる処理 |
| --- | --- |
| Samsungの表示調整 | カメラ終了後の専用待機スレッドを、GCに依存せず休止できるようにする |
| Windowsにリンク | 同じビーコン用DBの共有、受け渡しに失敗した後に到着した通信クライアントの解放 |
| Govee Home | Wi-Fi未接続中のBLE探索を停止し、再接続で復帰 |
| セサミ | Wi-Fi未接続中のBLE探索を停止し、再接続で復帰 |
| Earpiece EQ | 同じ出力先ID・検証用正規表現の再計算を再利用 |
| ECOVACS HOME | Matterコントローラー終了後の専用マルチキャストロック解放と、再利用時の取得 |
| ウェザーニュース | WxBeacon2をOFF・間隔変更したときの古い定期タイマー停止 |
| SmartThings | mDNS探索開始が中断し、解放処理へ引き継げなかった専用ロックの返却 |
| Tapo | Matter探索の同期的な開始失敗時に、その呼び出しが取得したロック参照を返却 |
| Simeji | 診断SDKの500ms周期のANR監視登録を停止 |
| LANDrop | 所有するFlutterエンジンの終了確認後、探索用ロックを解放 |
| Continuity Service | 一部の停止要求で例外が起きても残りのBLE停止要求を継続 |
| Digi Police | エリア通知OFF中の不要な測位サービスの開始抑止と終了時の受信処理解放 |

Goveeは起動保護との競合を避け、起動処理が終わってから準備します。それ以前に開始済みの探索には次回登録から作用します。

Govee・セサミのWi-Fi制限をONにすると、モバイル回線だけの間はBLEによる機器の検出・自動解錠などが使えなくなる場合があります。既存のBluetooth接続は切断しません。アプリが取り消した探索は、Wi-Fi再接続時にも再開しません。

Windowsにリンクの有効な接続・通知同期・ファイル転送の間隔や、EQの音声処理・生存確認の周期は変更しません。ECOVACSのロックはコントローラーが終了したと確認できた場合だけ解放します。画面を閉じただけでMatter接続を一律に終了する機能ではありません。

ウェザーニュースの補正は、フック読み込み後のセンサー設定変更から適用します。すでに参照を失ったタイマーを回収する機能ではありません。Simejiでは対象診断SDKの新しいANRレポートが取れなくなります。文字入力・変換・テーマや、Android本体の異常終了処理は変更しません。

最新の実装・検証範囲は[0.5.0の記録](docs/testing-0.5.0.md)を参照してください。電池削減量を一律に保証するものではありません。

LANDropは画面が所有するエンジンの終了を確認した場合だけ解放します。バックグラウンドの転送・探索中には解放しません。Continuity Serviceは純正の停止要求を最後まで進める補正です。

## Digi Policeの設定

「エリア通知を受信する」がOFFなのに測位サービスが動く状態を防ぎます。エリア通知サービスが終了した際、そのサービスが登録した位置情報の受信処理も解除します。ON中の要求間隔・精度、地図、着信ブロックの処理は維持します。

## 設定

1. release APKをインストールし、Vectorでモジュールと使用する対象アプリのスコープを有効にします。
2. App Battery Toolsの「状態」で解析完了を確認します。
3. 対象アプリを再起動します。OSの再起動は不要です。

「アプリ」タブに全体スイッチとアプリ別スイッチがあります。WindowsのDB共有と通信解放は別々に切り替えできます。変更は対象アプリの再起動後に反映されます。

## 常駐について

このアプリ自身に常駐サービス・定期タイマー・アラーム・定期ジョブはありません。フックは対象アプリ内で動き、初回解析と接続情報取得のスレッドは仕事が終わって1秒後に終了します。Androidがプロセスをキャッシュして残すことはありますが、定期監視はしません。

DexKitの結果はこのアプリの内部データだけに保存します。対象の初回・更新後、または解析ルールを変更した後だけ探索し、通常の起動・フック処理で全DEXを走査しません。

## 対応と制限

Digi Police 3.7.0で経路を確認しています。Javaのサービスと位置登録・解除はDexKitで型・意味・一意性を照合します。設定部分はDart製のため、検証したAOTの版だけでOFF判定を有効にします。設定モデルが変わった版では開始抑止を見送り、状態画面へ表示します。必要な通知を古い設定値で止めません。

電池持ちの改善幅は、元の不要な測位が発生していた時間によります。一律の削減率は保証しません。
