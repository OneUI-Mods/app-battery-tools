# AppBatteryTools 0.5.5

Multiple Picture Wallpaper（`jp.kamesan.android.multiple_picture_wallpaper_2`）を対象に追加しました。壁紙が別のアプリに隠れて4秒続いたあと、壁紙プロセスのGPUテクスチャとウィンドウバッファのキャッシュを解放します。実機では隠れている間の壁紙プロセスが約246MBから約194MBになりました。ホームに戻ると画像を再アップロードするため、最初の再描画だけ少し遅くなることがあります。壁紙の設定と画像は変更せず、サービスや定期監視は追加していません。

署名済みAPKを上書きして更新し、VectorのスコープにMultiple Picture Wallpaperを追加してください。壁紙アプリの強制停止は不要ですが、`am force-stop`すると本体が標準壁紙へ戻るため行わないでください。

Multiple Picture Wallpaper is now a target. Four seconds after every wallpaper engine is hidden, the wallpaper process releases its GPU texture and window-buffer caches. On a device the hidden wallpaper process dropped from about 246 MB to about 194 MB. Pictures upload again when Home returns, so the first redraw can be slightly slower. Wallpaper settings and images are unchanged, and no service or polling is added.

Install the signed APK as an update and add Multiple Picture Wallpaper to the module scope in Vector. Do not force-stop the wallpaper app: Android then falls back to the default wallpaper.
