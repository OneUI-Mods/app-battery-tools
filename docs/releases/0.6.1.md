# AppBatteryTools 0.6.1

Dynamic Island（mtisland）で、描画のために読み込んだアイコンを表示に足りる大きさ（見える部分で144ピクセル相当）に縮小してからキャッシュするようにしました。キャッシュに入るアイコンが増え、GPUに転送する画像も小さくなります。アダプティブアイコンとモノクロアイコンはレイヤーを保ちます。

署名済みAPKを上書きして更新してください。mtislandの次回起動から有効になります。

In Dynamic Island (mtisland), icons read for drawing are now reduced to the size they are shown at (144 visible pixels) before they are cached. More icons fit in the cache, and the images sent to the GPU are smaller. Adaptive and monochrome icons keep their layers.

Install the signed APK as an update. It takes effect the next time mtisland starts.
