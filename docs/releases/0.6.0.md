# AppBatteryTools 0.6.0

Dynamic Island（mtisland、`com.pryshedko.mtisland`）を対象に追加しました。このアプリは起動時に全アプリのアイコンを読み込み、すべてメモリに保持します。アイコンを描画するときだけ各アプリから読み込み、最近描いたものだけを16 MBのキャッシュに残すようにしました。アダプティブアイコンとモノクロアイコンはレイヤーを保ちます。ウィジェットのプレビューは長辺256ピクセル以下で保持します。実機では、mtislandが保持していたビットマップ約1,200枚（約261 MB）がなくなり、プロセス全体のメモリは約330 MB以上から約97 MBになりました。

対象アプリの固定をやめました。Vectorで対象を自由に選べます。対応していないアプリを選んだ場合、モジュールはそのアプリで何もせず、コードをすぐ手放します。

署名済みAPKを上書きして更新し、VectorでApp Battery Toolsの対象にmtislandを追加してください。mtislandの次回起動から有効になります。

Dynamic Island (mtisland, `com.pryshedko.mtisland`) is now a target. The app loads the icon of every launchable app when it starts and keeps them all in memory. Icons are now read from each app only while they are drawn, and only recently drawn ones stay in a 16 MB cache. Adaptive and monochrome icons keep their layers. Widget previews are kept at most 256 pixels on their longest side. On a device, the roughly 1,200 bitmaps (about 261 MB) mtisland held are gone, and the process dropped from over 330 MB to about 97 MB.

The module scope is no longer fixed, so you can choose apps in Vector. In an unsupported app the module does nothing and releases its code right away.

Install the signed APK as an update and add mtisland to App Battery Tools in Vector. It takes effect the next time mtisland starts.
